Getting started

Authentication & token handshake

All endpoints require a bearer token in the Authorization header.

Header schema

Authorization: Bearer <your_jwt>

HTTP headers
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
GET /api/v1/invoices

Retrieve own invoices

Paginated list of membership purchase transactions.

ParameterTypeRequiredDefaultDescription
pageIntegerNo1Page index
per_pageIntegerNo5Max 100
Response (200 OK)
{
  "status": "success",
  "pagination": { "page": 1, "per_page": 5, "total": 12 },
  "data": [
    { "tid": "45", "invoice_no": "MAH-2026-0045", "amount": "2500.00" }
  ]
}
GET /api/v1/invoices/{tid}

Invoice detail

Full invoice metadata including GST breakdown.

Dynamic GST

Telangana → CGST+SGST (9% each) · Other Indian states → IGST (18%) · International → 0%

Response (200 OK)
{
  "status": "success",
  "data": {
    "tid": "45",
    "invoice_no": "MAH-2026-0045",
    "gst_breakdown": { "type": "CGST+SGST", "cgst": 190.68, "sgst": 190.68 }
  }
}
GET /api/v1/invoices/{tid}/export

Export invoice PDF

Downloads a formatted PDF receipt. Content-Type: application/pdf

GET /api/v1/referrals/dashboard

Referral dashboard

Consolidated earnings, wallet balances, level counts, and bank status.

Response (200 OK)
{
  "data": {
    "earnings": { "total_earned": 28450.00, "available_balance": 12950.00 },
    "levels": [ { "level": 1, "count": 8, "amount": 8000.00 } ]
  }
}
GET /api/v1/referrals/levels?level=1

Level breakdown

Total downline counts per level. Add level param for member listing.

GET /api/v1/referrals/summary

Direct referral summary

Groups direct children into active, inactive, and non-referrals.

POST /api/v1/referrals/tree-children

Tree children

Fetch children for a given parent node.

Payload
{ "parent_id": 42 }
GET /api/v1/referrals/list?page=1&level=2

Commission log

Paginated commission receipts, filterable by level.

GET /api/v1/referrals/drilldown/{referid}

Payout drilldown

Total earned from a specific downline member.

GET /api/v1/withdrawals?status=2

Withdrawal history

Filter by status: 1=approved, 2=pending, 3=rejected.

POST /api/v1/withdrawals

Request withdrawal

Min ₹1000 · requires bank uploaded · PIN required.

Payload
{ "withdraw_amount": 1500.00, "transaction_pin": "123456" }
PUT /api/v1/withdrawals/bank-details

Upload bank details

Multipart form-data: bankaccount, ifsccode, upi_id, transaction_pin, idproof, bankproof.

Response (200 OK)
{
  "status": "success",
  "message": "Bank details updated successfully.",
  "notes": "Submitted to admin and admin is not liable for any discrepancy"
}

POST /api/v1/chat/messages

Send message

Multipart: receiver_id, message, file (image, max 5MB).

Payload

message: "Please see the attachment screenshot."
file: [File: image.png]
Response (201 Created)
{
  "status": true,
  "message": "Message sent successfully.",
  "data": {
    "id": "129",
    "sender": "101",
    "receiver": "admin_1",
    "message": "Please see the attachment screenshot.",
    "images": "chat/17848952.png",
    "created_at": "2026-07-24 19:16:15"
  }
}

    "complaint_id": 58,
